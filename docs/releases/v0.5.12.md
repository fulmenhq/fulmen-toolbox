# v0.5.12 - biome 2.5.15

**Date:** 2026-10-20

**Type:** Patch (biome pin; no image layout change)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with biome **2.5.15**. goneat stays at **v0.6.5**. syft **v1.54.1**, grype **v0.120.1**, trivy **v0.75.0**, and Go **1.26.9** are unchanged. `sbom-tools-runner-musl` moves Alpine curl to **8.14.1-r3** on x86_64 and aarch64. The other sbom-tools images and valkey-server are rebuilt with unchanged contents.

## Changes

1. `biome` `2.3.11` → `2.5.15` in the slim image and both full runners. Dockerfile ARGs, `manifests/tools.json`, the image README, and built-image `biome --version` checks move together.
2. Alpine `curl` `8.14.1-r2` → `8.14.1-r3` in `sbom-tools-runner-musl`. Alpine 3.21 publishes `-r3` on x86_64 and aarch64 and no longer serves `-r2`. The curl version is unchanged. `validate-apk-pins` checks every apk pin on linux/amd64 and linux/arm64, and the validate workflow runs that check.

## Upgrade notes

Consumers pinned to `:v0.5.11` (or its digest) should retag to `:v0.5.12` after GA. Verify an image with `cosign verify --certificate-identity https://github.com/fulmenhq/fulmen-toolbox/.github/workflows/release.yml@refs/tags/v0.5.12 --certificate-oidc-issuer https://token.actions.githubusercontent.com <image>@<digest>`, for the index digest or the platform digest you run. Checksum manifests verify with the keys from the repository at the tag; see `docs/security/release-signing.md`.

Biome 2.5 can reformat TypeScript, JavaScript, and JSON relative to 2.3. Re-run format on trees that biome checks, and set `biome.json` `$schema` to the 2.5.15 schema. Configurations that set `linter.rules.recommended` get an info diagnostic; biome 2.5 names `preset` instead.
