# v0.5.13 - Go 1.26.10, goneat v0.6.6, Node 22.23.4

**Date:** 2026-10-21

**Type:** Patch (toolchain and tool pins)

## Summary

Rebuilds the Go-built tools in `goneat-tools-slim-musl` with Go **1.26.10**. Rebuilds `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with the Go **1.26.10** toolchain, goneat **v0.6.6**, Node **22.23.4**, and golangci-lint **2.14.0**. The slim image does not ship `/opt/go` or golangci-lint. Rebuilds the sbom-tools images with trivy **v0.76.1** and shellsentry **v0.1.5** built with Go **1.26.10**. syft **v1.54.1** and grype **v0.120.1** stay. The npm **12.0.1** override stays.

## Upgrade notes

Consumers pinned to `:v0.5.12` (or its digest) should retag to `:v0.5.13` after GA. Verify an image with `cosign verify --certificate-identity https://github.com/fulmenhq/fulmen-toolbox/.github/workflows/release.yml@refs/tags/v0.5.13 --certificate-oidc-issuer https://token.actions.githubusercontent.com <image>@<digest>`, for the index digest or the platform digest you run. Checksum manifests verify with the keys from the repository at the tag; see `docs/security/release-signing.md`.

Building goneat from these images, or installing it with `go install` from the shipped toolchain, requires Go 1.26.10 or later.
