# v0.5.9 - goneat v0.6.3

**Date:** 2026-10-12

**Type:** Patch (tool pin; no image layout change)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with goneat **v0.6.3**. Go stays at **1.26.9**. goneat v0.6.3 changes no tool pins in its `.goneat/tools.yaml`, so syft, grype and the other scanner pins are unchanged.

## Changes

1. `goneat` `v0.6.2` → `v0.6.3` in the slim and both full runners. Dockerfile ARGs, `manifests/tools.json`, the Makefile bootstrap minimum, the image README, and built-image `goneat version` greps move together.

goneat v0.6.3 in the runners:

- Embedded schemas compile on first use, so every goneat invocation starts faster. `validate data --schema-file` drops from about 0.9 s to about 0.2 s per call.
- The security category reports gosec and govulncheck as not applicable in projects without a Go module. The runners do not ship gosec or govulncheck, so runner behavior for those tools is unchanged.
- Runners keep Go 1.26.9 on `PATH`. goneat v0.6.3's Go 1.27 guidance for gosec does not apply inside the runners.

## Upgrade notes

Consumers pinned to `:v0.5.8` (or its digest) should retag to `:v0.5.9` after GA. The release workflow builds and publishes all seven image variants on amd64 and arm64, including unchanged sbom-tools and valkey content, and advances `:latest` / `:v0` aliases on GA. Published artifacts require cosign image signing/SBOM attestations and manually signed per-image checksums under the release checklist.
