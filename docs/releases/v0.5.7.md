# v0.5.7 - goneat v0.6.1 and Rust runner scanners

**Date:** 2026-09-28

**Type:** Patch (tool pins and behavior verification; no image layout change)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with goneat **v0.6.1**. Both full runners also move to **cargo-deny 0.20.2** and **cargo-audit 0.22.2**. The Makefile bootstrap minimum is aligned to v0.6.1; Dockerfile ARGs and `manifests/tools.json` are the image pin sources. Rust 1.94.1 and Go 1.26.6 remain pinned.

## Changes

1. `goneat` `v0.6.0` → `v0.6.1` in the slim and both full runners. The Dockerfile Go install stamps `BinaryVersion` so `goneat version` reports v0.6.1, not the unstamped `dev`. Rust format and assessment now run cargo fmt; clippy and category execution errors fail instead of being hidden. Linked worktree handling and embedded Go dependency fixes are included.
2. `cargo-deny` `0.19.0` → `0.20.2` in both full runners. Upstream supplies amd64 and arm64 musl archives with `.sha256` sidecars, checked by the Dockerfile fetch stage.
3. `cargo-audit` `0.22.0` → `0.22.2` in both full runners. Upstream release provides amd64 musl, amd64 glibc and arm64 glibc archives but **no arm64 musl** archive. All fetched archives are SHA256-checked against pinned GitHub release asset digests: amd64 musl `7fb9497f8594b389e5fce5ef9b92db08432996895b2e0c5a0167a69ed445c428`, amd64 glibc `ab28a1bdb54db4d5d8ad5981cf1f959410370b3d28250dbd35f6a44248620e39`, arm64 glibc `c6603814ddaa45e51263dafd31c0ac98808f688d26f7395804f9670b0fd599dd`. On musl arm64 the glibc arm64 artifact is staged as before but not runnable; use the glibc runner for cargo-audit there.
4. musl `yq-go` `4.53.3-r0` → `4.53.3-r1` and `curl` `8.21.0-r0` → `8.22.0-r0`, since the previous Alpine 3.24 package revisions are no longer available. Dockerfile and manifest pins move together.
5. Built-image smoke assertions check exact goneat and scanner versions, clean and deliberately unformatted Rust fixtures, and a clippy compilation-error fixture. Both runner variants execute these tests in `make test-all` / `make prepush`.

## Upgrade notes

Previously passing CI may now fail when Rust formatting drift, a clippy execution error, invalid assessment configuration or a failing hook category was previously hidden. Rust formatting requires cargo and rustfmt when Rust is in scope; opt out intentionally through `format.rust.enabled: false` in `.goneat.yaml` if it is not wanted. Security scanner execution errors remain logged, not fail-closed; do not treat a successful security category as proof that every scanner completed.

The slim image still has no Rust toolchain. The `docs/images/goneat-tools.md` behavior note describes the Rust assessment exception; pinned versions live only in the Dockerfiles and manifest. No gofulmen binary is bundled.

Consumers pinned to `:v0.5.6` (or its digest) can retag to `:v0.5.7` after release. All seven images are built on native amd64 and arm64 in the existing release matrix; unchanged sbom-tools and valkey images are republished and compatibility aliases plus `:latest` / `:v0` advance on GA. Published artifacts require cosign image signing/SBOM attestations and manually signed per-image checksums under the release checklist.
