# v0.5.10 - goneat v0.6.4, pinned release keys, every image platform signed

**Date:** 2026-10-14

**Type:** Patch (tool pins; release signing and verification; no image layout change)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with goneat **v0.6.4** and sfetch **v0.4.13**, and the goneat runners and the three sbom-tools images with syft **v1.54.1** and grype **v0.120.1**. Go stays at **1.26.9**. valkey-server contents are unchanged. Release verification uses release keys committed in the repository, and the release workflow signs the multi-arch index and every platform manifest of every image under every published name.

## Changes

1. `goneat` `v0.6.3` → `v0.6.4` in the slim and both full runners. Dockerfile ARGs, `manifests/tools.json`, the Makefile bootstrap minimum, the image README, and built-image `goneat version` greps move together.
2. `sfetch` `v0.4.9` → `v0.4.13` in the slim and both full runners.
3. `syft` `v1.54.0` → `v1.54.1` and `grype` `v0.120.0` → `v0.120.1` on the goneat runners and sbom-tools. grype v0.120.1 still vendors `docker/docker` v28.5.2; the `.trivyignore` waiver is re-dated.
4. **Release keys are committed.** `keys/expected-fingerprints.txt`, `docs/security/release-signing-keys.asc` and `docs/security/release-minisign.pub` hold the release keys, the same keys that sign goneat. `make release-verify-signatures` reads them from the release tag, requires the tag to be signed by the pinned signing subkey, and checks every manifest against them. `make release-sign` refuses operator keys that do not match.
5. **Every image platform is signed.** The release workflow signs the multi-arch index digest and each platform manifest under the image name and every alias, attests each platform manifest with an SBOM generated from that platform, and verifies all of them against the release workflow identity. Earlier releases signed only the first platform manifest listed in the index.
6. Release assets add `DIGESTS-<image>` (index and platform manifest digests) and one SBOM per platform: `sbom-<image>-<version>-<os>-<arch>.json`. The single `sbom-<image>-<version>.json` is no longer published.

goneat v0.6.4 in the runners:

- goneat no longer starts package manager processes at startup, so each invocation starts faster.

## Upgrade notes

Consumers pinned to `:v0.5.9` (or its digest) should retag to `:v0.5.10` after GA. Verify an image with `cosign verify --certificate-identity https://github.com/fulmenhq/fulmen-toolbox/.github/workflows/release.yml@refs/tags/v0.5.10 --certificate-oidc-issuer https://token.actions.githubusercontent.com <image>@<digest>`, for the index digest or the platform digest you run. SBOM attestations are on platform digests only. Checksum manifests verify with the keys from the repository at the tag; see `docs/security/release-signing.md`.
