# v0.5.8 - goneat v0.6.2, Go 1.26.9, scanner lockstep

**Date:** 2026-10-10

**Type:** Patch (tool pins; no image layout change)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with goneat **v0.6.2** and Go **1.26.9**. Rebuilds the sbom-tools variants with **syft v1.54.0**, **grype v0.120.0**, and **trivy v0.75.0** in lockstep with goneat v0.6.2 `.goneat/tools.yaml` (syft/grype) and goneat's 7-day cooling window (trivy v0.75.0 published 2026-10-01). musl `libssl3`/`libcrypto3` remain **3.5.9-r0**. Medium amd64/arm64 GitHub runners already landed on main via #23.

## Changes

1. `goneat` `v0.6.1` → `v0.6.2` in the slim and both full runners. Dockerfile ARGs, `manifests/tools.json`, the Makefile bootstrap minimum, and built-image `goneat version` greps move together.
2. Go toolchain `1.26.6` → `1.26.9` on slim and both full runners: `GO_VERSION` + tarball SHA256 (amd64 `42d158b4d8f7b61ac0a830567c940a86098fb7aac52e467a5ebec03ef5cc2f8d`, arm64 `4a97373d49fcacdcf3694fea368a500b00ee3e963974f3e7514132717632f052`, verified from `https://go.dev/dl/?mode=json&include=all`) + the coupled `GO_IMAGE` builder digest, kept in sync. Builder images are pinned to `golang:1.26.9-alpine@sha256:3082400e369fa24d5fc60bca20edab3f6d604e0c5a690ec66b295eff4dd87ade` and `golang:1.26.9-bookworm@sha256:d9c68c2c51161e12fd77e4c6320687c9cd86e1af1e3ad6e6cd63ff970641453c` (verified via Docker Hub manifest `Docker-Content-Digest`).
3. Scanners lockstep: `syft` `v1.50.0` → `v1.54.0` and `grype` `v0.116.1` → `v0.120.0` on goneat runners and sbom-tools (goneat v0.6.2 recommended/minimum). `trivy` `v0.72.0` → `v0.75.0` on sbom-tools only.
4. musl `libssl3`/`libcrypto3` stay at `3.5.9-r0` (already on main from #23; Alpine 3.24 APKINDEX still serves that revision). Every other apk/apt pin was re-checked against current Alpine 3.24/3.21 and Debian bookworm(+security) indexes; none had rotated out.
5. `.trivyignore` re-evaluated from upstream go.mod of the new scanner pins (no local Docker image rebuild in this environment). Dropped trivy-only waivers `CVE-2026-50151` (oras-go v2.6.2 in trivy v0.75.0) and `GHSA-hrxh-6v49-42gf` (grpc v1.83.2). Dropped Go-stdlib waivers whose fix is older than syft/grype/trivy's current toolchains. Kept residuals still carried by yq, golangci-lint, grype's vendored `docker/docker` v28.5.2, and the npm 12.0.1 brace-expansion pin.
