# v0.5.4 — Go 1.26.6 runner rebuild + security pin refresh

**Date:** 2026-09-01

**Type:** Patch (image content pins; security-advisory driven; no consumer contract break)

## Summary

Rebuilds the goneat-tools images with the Go toolchain at **1.26.6** (`GO_VERSION` + tarball checksums + the coupled `GO_IMAGE` builder digests, kept in sync on both musl and glibc), refreshed **node base digests** shipping node 22.23.2, and the **jq 1.8.2** upstream binary (with checksum verification) on the glibc runner. goneat stays at v0.5.16. Unlike v0.5.1, this cut **changes image contents**.

## Motivation

Scanning the `:v0.5.3` GA images shows the single largest finding cluster is the Go standard library itself: 13 HIGH advisories in every in-runner-built Go binary (goneat, sfetch, shellsentry, golangci-lint, shfmt, actionlint, yamlfmt, checkmake, and the shipped `/opt/go` toolchain), all fixed in 1.26.6. The musl `libssl3`/`libcrypto3` critical cluster persists across rebuilds: the pinned node base bundles `3.5.7-r0`, and `apk add` does not upgrade satisfied dependencies, so this cut pins the patched `3.5.8-r0` explicitly — see Changes §5. Node 22.23.2 and jq 1.8.2 are the same-class advisory-fixable pins folded into the same rebuild.

## Changes

1. **Go `1.26.5` → `1.26.6`** on `goneat-tools-slim-musl` and `goneat-tools-runner-{glibc,musl}`: `GO_VERSION` + tarball SHA256 (amd64/arm64) + the coupled `GO_IMAGE` builder digest, kept in sync. Builder images are pinned to the **patch-specific tags** `golang:1.26.6-alpine` / `golang:1.26.6-bookworm` (verified to resolve `go version go1.26.6`): the floating `golang:1.26-alpine` / `golang:1.26-bookworm` tags have already moved to 1.26.7, which would break the builder↔runtime patch coupling.
2. **Node base digests refreshed on both images** — `node:22-alpine` (musl) and `node:22-bookworm-slim` (glibc) now pin digests shipping **node 22.23.2** (was 22.23.1; clears 3 HIGH advisories). The base bundles npm 10.9.8, still below our pinned npm 12.0.1 override, so the npm override stage stays.
3. **`jq` `1.8.1` → `1.8.2` on `goneat-tools-runner-glibc`** — upstream GitHub release binary, now **checksum-verified in the build** (`JQ_SHA256_AMD64` / `JQ_SHA256_ARM64` args + `sha256sum -c` in the fetch stage, mirroring the Go-tarball pattern). The `manifests/tools.json` row records both upstream SHA256 values. The shared glibc jq row was split so `sbom-tools-runner-glibc` (out of this cut) stays at 1.8.1.
4. **musl jq held at `1.8.1-r0`** — the Alpine 3.24 repos (the musl base's repos) do not carry a jq 1.8.2 package yet (`validate-apk-pins` green against upstream). The bump lands when the apk pin resolves; it did not block this cut.
5. **musl `libssl3`/`libcrypto3` explicitly pinned to `3.5.8-r0`** — the pinned `node:22-alpine` (22.23.2) base bundles `3.5.7-r0`, and `apk add` does not upgrade satisfied dependencies, so the patched build is pulled explicitly from the Alpine 3.24 repos, clearing `CVE-2026-63073` (CRITICAL) + 7 HIGH per lib. Availability is enforced by `validate-apk-pins`; pin presence by `validate-pins`.
6. **libssl/libcrypto criticals on musl** clear via the explicit pins above (no base-image change).
7. **Release pack** — `VERSION` 0.5.4, release notes/changelog/docs in agreement.

## Non-goals (this cut)

- Debian bookworm → trixie base migration (tracked as its own cut).
- Alpine rebase beyond 3.24; sbom-tools `alpine:3.21` refresh.
- syft 1.50 / grype 0.116.1 / yq bumps (cooling-exception pin from the goneat scanner wave; revisit when upstream ships 1.26.6-built binaries).
- golangci-lint 2.13.x, biome 2.5.x, ruff 0.16, cargo-deny 0.20.
- goneat newer than v0.5.16.
- sbom-tools image rebuild (its jq row intentionally stays at 1.8.1).

## Known residuals (not clean — read before relying on scan results)

- **Prebuilt `syft`/`grype`/`yq` binaries retain Go stdlib HIGHs** — upstream ships them built with older Go (go1.26.3/1.26.4). Fix is upstream-rebuild-bound.
- **Embedded module advisories in `goneat`** (go-git 5.19.1, x/crypto 0.54.0, x/mod 0.38.0) — owned by the goneat dependency-refresh task, then re-embedded on the next goneat pin bump.
- **Debian bookworm OS criticals on the glibc runner** (`curl`, `libc6`, `perl`, `libssh2-1`, `openssh-client`) — no-fix upstream in bookworm; latest bookworm patches are already shipped. Classified **no-fix / base-migration deferred**, not EOL.
- **musl jq remains 1.8.1-r0** until Alpine 3.24 publishes 1.8.2.

## Upgrade notes

Consumers tracking `:v0.5.3` (or a digest from that tag) should retag to `:v0.5.4` to pick up the Go 1.26.6 toolchain and stdlib fixes. Floating `:v0` / `:latest` move on GA. No interface change: same binaries, same paths, patched builds. `goneat` is unchanged at v0.5.16, so downstream consumers of goneat behavior see no delta from this cut.

After this ships, downstream consumers (including goneat's CI) retag their runner references `:v0.5.1`/`:v0.5.3` → `:v0.5.4`.
