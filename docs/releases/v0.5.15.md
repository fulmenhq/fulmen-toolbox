# v0.5.15 - goneat v0.6.8, sfetch v0.4.15, npm 12.2.1

**Date:** 2026-11-10

**Type:** Patch (tool pins, CVE fix)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl`, and `goneat-tools-runner-glibc` with goneat **v0.6.8**, sfetch **v0.4.15**, and npm **12.2.1**. npm 12.2.1 bundles the brace-expansion release that fixes CVE-2026-14257, so the `.trivyignore` entry is removed. Both full runners move to uv **0.13.4**, and all three goneat images overlay undici **6.29.1** over the copy bundled in npm. syft moves to **v1.56.0** and grype to **v0.121.1** on the runners and sbom-tools images, with SHA256-pinned tarballs. `musl` **1.2.6-r3** and `apt` **2.6.2** are pinned to clear two HIGH OS findings. The sbom-tools images move to new Alpine 3.21 and Debian bookworm-slim base digests. Also includes the merged changes #35, #36 and #37. Go **1.26.10**, Node **22.23.4**, golangci-lint **2.14.0**, shellsentry **v0.1.7**, and trivy **v0.76.1** are unchanged.

## Changes

1. `goneat` `v0.6.6` → `v0.6.8` in the slim image and both full runners. Dockerfile ARGs, `manifests/tools.json`, the Makefile bootstrap minimum, the image README, and built-image `goneat version` checks move together. goneat v0.6.8 is inside the 7-day cooling window. The exception runs until 2026-11-17T17:29:02Z. See `docs/operations/2026-11-10-goneat-cooling-exception.md`.
2. `sfetch` `v0.4.14` → `v0.4.15` in the slim image and both full runners. sfetch v0.4.15 was published at 2026-10-24T19:11:33Z (module proxy time), so it is outside the cooling window.
3. `npm` `12.0.1` → `12.2.1` in the slim image and both full runners. The `CVE-2026-14257` entry and its comment block are removed from `.trivyignore`. The npm tarball is fetched with the base image's npm and installed only after its sha512 integrity matches the committed `NPM_INTEGRITY`.
4. `uv` `0.9.28` → `0.13.4` in both full runners. uv is installed in its own `pip install --require-hashes --no-deps --only-binary=:all:` step against the committed sha256 of the uv 0.13.4 Linux amd64 and arm64 wheels (`UV_WHEEL_SHA256`). 0.13.4 was published 2026-10-20T15:11:02Z and carries the bundled CA store fix for GHSA-hq85-5cpj-mr62. Compatibility: the 0.10 to 0.13 breaking changes concern `uv venv` clearing, index and hash handling, wheel and archive validation, `uv init` defaults and the default Python version. The images and repository scripts only run `uv --version`, and consumers keep uv's behavior for their own projects at the version they install.
5. undici overlay in the slim image and both full runners. npm 12.2.1 bundles undici 6.29.0 (CVE-2026-109383, CVE-2026-109869, CVE-2026-87018). After `npm install -g npm@12.2.1`, the Dockerfiles unpack the registry tarball for undici 6.29.1 (published 2026-10-15T14:19:28Z) over npm's copy, verified against a pinned sha512 integrity, and ship its LICENSE. Removal condition, recorded in `manifests/tools.json`: remove the overlay when an npm release bundles undici 6.29.1 or newer.
6. `syft` `v1.54.1` → `v1.56.0` and `grype` `v0.120.1` → `v0.121.1` on both full runners and all three sbom-tools images (both published 2026-11-02). Both are built with go1.27.3 and use go-jose v4.1.6, so their Go standard-library and go-jose findings clear. The release tarballs are verified against pinned per-architecture SHA256 values, like trivy. The hashes come from each release's `checksums.txt`, which was verified with `cosign verify-blob` against its `checksums.txt.sigstore.json` bundle (signed by Anchore's release workflow), and match independently downloaded assets. grype still vendors docker/docker v28.5.2: CVE-2026-41567 and CVE-2026-42306 have no fixed version, and CVE-2026-34040 stays waived in `.trivyignore`.
7. OS security pins: `musl` and `musl-utils` `1.2.6-r2` → `1.2.6-r3` in `goneat-tools-slim-musl` and `goneat-tools-runner-musl` (CVE-2026-107891, built 2026-10-21), and `apt` and `libapt-pkg6.0` `2.6.1` → `2.6.2` in `goneat-tools-runner-glibc` and `sbom-tools-runner-glibc` (CVE-2026-109518, DSA-6607-1, 2026-11-02). The pinned base images ship the vulnerable builds; the explicit pins pull the patched packages. Alpine `zlib` 1.3.2-r0 (CVE-2026-85091) stays: Alpine 3.24 ships the fix only as zlib 1.4-r0, built 2026-11-06, inside the cooling window. It is listed in the residual-findings document.
8. sbom-tools base digests: `alpine:3.21@sha256:ee16d92f96db08d9d2d07da48555a27f3a69d8f0759021dbc601195ed0d2b5bd` (Docker Hub push 2026-10-23T05:24:18Z) and `debian:bookworm-slim@sha256:7ff6ba31527b9e336162fa061746c366c4b2032f4d2cff2078bea43f78efe3f8` (the `bookworm-20261020-slim` build, push 2026-10-21T01:36:39Z). Both were pushed more than 7 days before adoption. The `bookworm-20261027-slim` build was pushed 2026-10-28T02:24Z and is not adopted. Alpine 3.21 reached end of life on 2026-11-01; the manifest, sbom-tools README and `docs/inventory.md` say so.
9. `docs/operations/2026-11-02-residual-findings-exception.md` records the remaining HIGH/CRITICAL findings in syft, grype, trivy and the glibc yq binary, with a 2026-11-16 recheck. It is not a cooling exception; approval is pending.
10. Alpine 3.24 `curl` `8.22.0-r0` → `8.23.0-r0` in `goneat-tools-runner-musl`. Alpine no longer serves 8.22.0-r0 (#35).
11. `gpg` and `gpg-agent` `2.2.40-1.1+deb12u2` are pinned in `goneat-tools-runner-glibc` (#37).
12. `make validate-licenses` runs in a dedicated, cached `validate-licenses` CI job in parallel with the other validate jobs (#36).

## Upgrade notes

Consumers pinned to `:v0.5.14` (or its digest) should retag to `:v0.5.15` after GA. Verify an image with `cosign verify --certificate-identity https://github.com/fulmenhq/fulmen-toolbox/.github/workflows/release.yml@refs/tags/v0.5.15 --certificate-oidc-issuer https://token.actions.githubusercontent.com <image>@<digest>`, for the index digest or the platform digest you run. Checksum manifests verify with the keys from the repository at the tag; see `docs/security/release-signing.md`.
