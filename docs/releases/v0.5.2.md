# v0.5.2 — Runner content pins (Rust 1.94.1)

**Date:** 2026-08-19

**Type:** Patch (image content pins; no consumer contract break)

## Summary

Rebuilds the goneat-tools images with three pinned bumps: Rust 1.94.1 on the full runners, goneat v0.5.16 on slim and both runners, and pytest 9.1.1 on the full runners. OS APK/APT pins are unchanged. Unlike v0.5.1, this cut **changes image contents**.

## Motivation

v0.5.1 was a release-pipeline hygiene tag; published image contents were still v0.5.0, including Rust 1.92.0. Crates whose transitive `rust-version` is 1.94.1 (AWS SDK / smithy 1.3+ is the first known consumer class) cannot compile on 1.92.0. A newer rustc builds older crates; an older rustc cannot satisfy that floor.

The same rebuild folds goneat v0.5.16 (released; dogfoods toolbox v0.5.1 in goneat's own CI) and a pytest patch so consumers take one image cascade, not three.

## Changes

1. **Rust `1.92.0` → `1.94.1`** on `goneat-tools-runner-{glibc,musl}`. rustc, cargo, rustfmt, and clippy move together via rustup. The image does **not** set `RUSTUP_TOOLCHAIN` (that env overrides a consumer `rust-toolchain.toml`). rustup's default toolchain is 1.94.1. Slim remains Rust-free. The existing seven rustup targets are unchanged.
2. **`goneat` `v0.5.15` → `v0.5.16`** on `goneat-tools-slim-musl` and both full runners. v0.5.16 does not change the fail-closed formatter preflight introduced in v0.5.15.
3. **`pytest` `9.0.2` → `9.1.1`** on both full runners (pip pin + `manifests/tools.json`).
4. **`scripts/validate-pins.sh`** now checks `ARG RUST_VERSION` and `ARG PYTEST_VERSION` against `tools.json` on both goneat-tools Dockerfiles (same class of check as `GO_VERSION`).

## Non-goals (this cut)

- Jumping to current Rust stable (1.97.x). 1.94.1 is the floor, not a latest-stable chase.
- Installing extra rustup toolchains in the image.
- Putting Rust on slim images.
- OS APK/APT pin refresh.
- Prettier, Biome, uv, ruff, cargo-deny, syft, grype, or trivy bumps.
- Changing goneat CI in the goneat repository (retarget the runner tag after this ships).

## Upgrade notes

Consumers tracking `:v0.5.1` (or a digest from that tag) must retag to `:v0.5.2` to pick up the new toolchain. Floating `:v0` / `:latest` move on GA.

rustfmt and clippy are **not** in the Rust language stability promise. `goneat format --check` and clippy-deny-warnings on older repos may differ from 1.92.0 output.

Repos that pin an older channel in `rust-toolchain.toml` can still rustup-install that channel when CI has network; the image default is 1.94.1.
