# v0.5.11 - goneat v0.6.5, release stays a draft until signed

**Date:** 2026-10-17

**Type:** Patch (goneat pin; release workflow; no image layout change)

## Summary

Rebuilds `goneat-tools-slim-musl`, `goneat-tools-runner-musl` and `goneat-tools-runner-glibc` with goneat **v0.6.5**, and moves the musl slim image's Alpine `yq-go` package to **4.53.3-r2**. syft **v1.54.1**, grype **v0.120.1** and trivy **v0.75.0** are unchanged. Go stays at **1.26.9**. sbom-tools and valkey-server are rebuilt with unchanged contents. The GitHub release now stays a draft until its signatures are uploaded and verified.

## Changes

1. `goneat` `v0.6.4` → `v0.6.5` in the slim and both full runners. Dockerfile ARGs, `manifests/tools.json`, the Makefile bootstrap minimum, the image README, and built-image `goneat version` checks move together.
2. Alpine `yq-go` `4.53.3-r1` → `4.53.3-r2` in `goneat-tools-slim-musl`. Alpine rebuilt the package and no longer serves `-r1`; the yq version is unchanged.
3. **Release stays a draft until signed.** A `draft-release` job creates the GitHub release as a draft before any manifest job uploads release assets, and fails if the release is already published. Manifest jobs upload their assets into the draft and hand `DIGESTS-<image>` and the per-platform SBOMs to the cosign job as workflow artifacts. `make release-upload` checks every manifest against the signed local copy before uploading, downloads and re-verifies the release against the committed release keys afterwards, then publishes it with `docs/releases/<tag>.md` as the notes and marks it latest. A failed check leaves the release a draft.

goneat v0.6.5 in the runners:

- `goneat dependencies --licenses` and `--sbom` no longer report "incomplete Rust license inventory" for Rust workspaces that cargo-deny inventories without errors. goneat builds the expected crate set the way cargo-deny does.
- Slash-separated crate licenses such as `MIT/Apache-2.0` are compared as OR, as cargo-deny parses them.
- goneat v0.6.5 requires syft 1.54.1 and grype 0.120.1 as both minimum and recommended versions; the runners already ship them.

## Upgrade notes

Consumers pinned to `:v0.5.10` (or its digest) should retag to `:v0.5.11` after GA. Verify an image with `cosign verify --certificate-identity https://github.com/fulmenhq/fulmen-toolbox/.github/workflows/release.yml@refs/tags/v0.5.11 --certificate-oidc-issuer https://token.actions.githubusercontent.com <image>@<digest>`, for the index digest or the platform digest you run. Checksum manifests verify with the keys from the repository at the tag; see `docs/security/release-signing.md`.
