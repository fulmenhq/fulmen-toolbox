# v0.5.3 — Runner content pins (Prettier 3.9.6)

**Date:** 2026-08-31

**Type:** Patch (image content pins; no consumer contract break beyond formatter output drift)

## Summary

Rebuilds the goneat-tools images with four pinned bumps: Prettier 3.9.6 on slim and both full runners, actionlint v1.7.12 and shfmt v3.13.1 on the same set, and golangci-lint v2.12.2 on both full runners. OS APK/APT pins and goneat v0.5.16 are unchanged. Unlike v0.5.1, this cut **changes image contents**.

## Motivation

goneat v0.5.16 already recommends Prettier 3.9.6. The published runner still installed 3.8.0, so repositories that took the recommended pin failed format checks in hosted CI. The same rebuild folds three goneat-recommended patch alignments (actionlint, shfmt, golangci-lint) so consumers take one image cascade.

## Changes

1. **`prettier` `3.8.0` → `3.9.6`** on `goneat-tools-slim-musl` and `goneat-tools-runner-{glibc,musl}`.
2. **`actionlint` `v1.7.10` → `v1.7.12`** on slim and both full runners.
3. **`shfmt` `v3.12.0` → `v3.13.1`** on slim and both full runners. This is the goneat recommended pin, not shfmt 3.14.0.
4. **`golangci-lint` `v2.12.1` → `v2.12.2`** on both full runners. Built in-runner against Go 1.26.5. Not a jump to 2.13.x. Slim remains without golangci-lint.
5. **`scripts/validate-pins.sh`** now checks `ARG GOLANGCI_LINT_VERSION` against `tools.json` on both goneat-tools Dockerfiles.

## Non-goals (this cut)

- Biome 2.5.x, ruff 0.16, uv 0.12, cargo-deny 0.20.
- shfmt 3.14.0 or golangci-lint 2.13.x.
- Bumping goneat past v0.5.16.
- OS APK/APT pin refresh.
- Changing goneat CI in the goneat repository (retarget the runner tag after this ships).

## Upgrade notes

Consumers tracking `:v0.5.2` (or a digest from that tag) must retag to `:v0.5.3` to pick up the new pins. Floating `:v0` / `:latest` move on GA.

Prettier 3.9.x may emit different Markdown/JSON than 3.8.0. Re-run `prettier --check` / `goneat format --check` on consumer trees after switching images.
